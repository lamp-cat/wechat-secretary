AI 服务 …

用于「历史总结」和「回复建议」。兼容任意 OpenAI 格式接口。只生成草稿，永远不会自动发送。

API Key
高级

保存到 （权限 0600），立即生效，无需重启。Key 不会回显，也不会写入日志。

访问令牌（鉴权）

令牌 = 完整访问权限（可读取全部消息）。请妥善保管，不要发到群里或截图外传。

自定义令牌

重置后本窗口自动保持登录；其它浏览器需重新登录，飞书秒搭等外部调用需把 Authorization: Bearer 换成新令牌。

微信数据源 …


      

        本机已抓取过数据库密钥，日常启动直接复用，不需要再抓。仅当微信升级后「验证密钥」失败时才需要重新抓取：
        这是一次性的 Frida 步骤，需要先完全退出微信，用一份临时签名的微信副本启动并捕获密钥（不修改正式版微信、不关闭 SIP）。
        点击后会在「终端」中打开引导脚本，每一步都会让你确认。新电脑上首次使用同样需要走这一步，并非全自动。
      

    


    

      
消息归档 …

      
开启后，自动把消息持续复制到本机一个独立文件夹（SQLite 数据库 + 每个会话一份 Markdown + 附件），
        供豆包等不能直接读取聊天软件的 AI agent 当作普通资料读取。默认关闭，数据只存本机，不上传。
